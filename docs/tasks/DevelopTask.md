## 2. 收信与本地库

有了真实来源再落库。在这之前不建空的 Repository。

- [ ] 邮件头、已读、文件夹、归档、分类、标签、同步进度进本地库
- [ ] 首次同步：先显示最近 7 天的信头
- [ ] 再补历史：30 天或全部邮箱合计 50 封，取更小的那个停
- [ ] 7 天已满 50 封则不补更早
- [ ] 头字段含发件人、收件人、抄送、主题、时间、已读、附件标记、账号、文件夹、服务器邮件 ID
- [ ] UID + UIDVALIDITY 增量，不做每次全量
- [ ] 前台 IMAP IDLE；不支持或被挂起时 15 分钟定时拉取
- [ ] 打开应用且有网时，只刷新当前列表范围
- [ ] 已读以本应用为准，并回写服务器
- [ ] 网络、解析、写库不占主线程；滑动或动画时不抢界面
- [ ] 厂商自带分类不参与判断，也不进提示词
- [ ] 归档后的信留在服务器原文件夹；同步不要把它放回收件箱

## 3. 正文与阅读

- [ ] 未处理邮件在后台洗成安全 HTML 和轻量 Markdown，并写成文件
- [ ] 数据库只记路径和处理时间，不存正文
- [ ] 外链图片默认不请求；纯文本邮件走同一套文件
- [ ] 打开未洗好的信时先处理这一封，列表仍可滑
- [ ] 默认用 Markdown 阅读，不在进列表时创建 WebView
- [ ] 全局只有一个 WebView；空闲约半秒、且没有按压、惯性滑动、转场或分栏拖动时才创建
- [ ] 阅读中途 WebView 就绪，不替换当前这封；换一封或点「按原版式查看」才换
- [ ] 链接用系统浏览器打开
- [ ] 宽屏拖分界线时，WebView 松手后再按最终宽度重绘

## 4. 分类与标签池

- [ ] 每封信最多请求一次 DeepSeek；密钥和模型名来自设置
- [ ] 提示词按类型带上活跃、陈旧、待定三个池，并要求先复用原词
- [ ] 类型只取重点、验证、通知、推广、垃圾；标签 0～3 个
- [ ] 失败可重试，且不挡住列表
- [ ] 待定标签按 45 天、次数和间隔规则升入活跃池
- [ ] 活跃标签 180 天未用变为陈旧；再用回到活跃
- [ ] 设置里按类型手动增删活跃池和待定池
- [ ] 未分类的收件箱信显示安静的「分类中」

## 5. 手势

分界线拖动已在骨架完成。这里补需求第 7 节剩下的部分，做的时候收成一个手势，不要在行上再挂一套监听。

- [ ] 列表横滑打开或收起遮罩；边缘让给系统返回
- [ ] 长按松手进入多选；接着左滑或右滑走快捷操作，不带动遮罩；接着纵滑取消
- [ ] 左滑：回复、删除。右滑：加标签、归档。过滑有阻力
- [ ] 多选时在复选框列上滑动连选；系统返回退出多选
- [ ] 删除和归档先拿走，几秒内可撤销，超时再写服务器
- [ ] 窄屏内容横滑回列表；宽屏内容横滑关闭当前邮件
- [ ] 头像和自建聚合长按排序，拖出列有阻力并弹回
- [ ] 快捷操作档位的短触感；长按成立本身不震动
