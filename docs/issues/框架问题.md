# 框架问题

版本：0.3
日期：2026-11-15
范围：框架审阅里要改的结构已经收口。下面只留明确不做的事。

---

## 已经收口

1. 列表和邮箱状态不再互相引用。时间、头像字和色相在投影里算完，列表只负责上色。
2. 删除、归档、打标签走同一个 `reduce`。发布只留在 ViewModel 末尾。打标签的结果从这次归约带回。
3. 导航只压栈和出栈。当前板块里还在的信放在 `sectionMailIds`。正文和回复主题按导航给出的 id 取展示模型，打开的信不写入会话。
4. 根界面只订阅范围、板块、账号和提示。列表单独一份状态。账号的 id 和名字没变时沿用原来的列表。
5. 列表、正文、遮罩上的横滑先拿掉。长按和横滑等手势那一节再做，不留半成品监听。
6. 登录、聚合、原版式、写信这些还没做的提示留在界面，不进归约。
7. 头像着色在壳层。分栏比例只在恢复存档时夹进允许范围。
8. 板块是 `Section`。服务器文件夹是 `RemoteFolder`，没有存档。存档是 `archived`，只从收件箱里挪到存档板块。
9. 标签池是 `TagCatalog`。邮件上只留标签名。一个新词不能同时进两个类型的池。45 天、180 天的衰减还没写。
10. `MailboxViewModel` 的构造函数接收邮件、账号和目录。样例由 `MailApp` 传进去。
11. 撤销只记住被改动的信原来的文件夹和归档标记。
12. 切换账号范围或板块时清掉多选。
13. 提示是原因，文案留在界面。会改会话的提示才进归约。
14. 账号范围是 `MailboxScope`：全部，或某一个账号。
15. 全屏按钮回到 `ui.shell`。设置页不再引用正文包。

---

## 明确留着

- 宽屏空右栏仍是详情和设置两种。第三种左栏再改 `TwoPaneStrategy`。
- 不建 Repository，也不做只有一个实现的接口。
- 标签衰减、过期、升入活跃池还没做。规则以后写成目录旁边的纯函数，ViewModel 只调用。
- `Mail.body` 仍是内存里的占位正文。列表投影不准读它。清洗后的文件以后再接。
- 自建聚合还没有第三种范围。有数据时再加，不留空类型。
- 账号授权码和刷新令牌以后放进同一份加密文件里的另一段记录，不加进现在的 `Secrets` 字段。
