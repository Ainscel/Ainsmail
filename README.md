# MyMail

MyMail 是一款 Android 原生邮箱应用。它面向个人自用，用 Kotlin 与 Jetpack Compose 编写，用来接收并阅读你自己的多个邮箱。

市面上常见的大厂邮箱往往功能堆叠、界面嘈杂，打开和滑动时也容易显得沉重。MyMail 想走另一条路：去掉多余累赘，把帧率、流畅和手感放在第一位，再用现代、克制的视觉语言把界面做干净。

## 产品目标

- **性能优先。** 卡顿和发烫都不可接受。网络同步、正文清洗、模型分类和光效都不能压过滑动与切换。
- **交互要丝滑。** 列表滚动、页面切换、侧栏开合、分栏拖动都应当跟手，尽头用阻力和回弹，而不是硬停。
- **视觉要现代，但克制。** 界面干净耐看；少量流光可以出现在顶栏、选中态等少数表面，不会铺满屏幕。

## 它能做什么

第一版会支持 **QQ 邮箱**（含 Foxmail）和 **Gmail**。你可以把账号分开看，也可以把多个邮箱合成一个列表，或者自己建一组聚合。

手机上是列表进正文；折叠屏展开或平板足够宽时，同一套交互变成左列表、右正文，中间的分界线可以拖动。账号和板块从左侧滑出的遮罩进入，不额外塞进第三栏。

收信走 IMAP。Gmail 用你自己在设置里填写的 Google 桌面应用 OAuth 客户端登录，再以 XOAUTH2 连接邮箱；应用不会把客户端 ID、客户端密钥或 DeepSeek 密钥写进安装包和仓库。邮件正文会洗成适合阅读的安全 HTML，以及给模型用的轻量 Markdown。DeepSeek 负责给每封信判断类型，并打上最多三个标签；标签池的活跃、陈旧与待定由本地规则维护。

阅读时默认不启动 WebView。列表滑动保持轻量；需要看原版式时，再按需切换。写信入口会留出来，但当前阶段还不发送邮件。

## 技术栈

Kotlin · Jetpack Compose · Navigation 3 · Android 原生

## 当前状态

MyMail 仍处于开发阶段。仓库里的功能与界面会持续变化，暂时还不能当作日常邮箱使用。
