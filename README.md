# Ainsmail

Ainsmail 是一款面向个人使用的 Android 邮箱。它用来接收并阅读自己的多份邮件，把看信这件事做得轻、顺、清楚。
市面上常见的大厂邮箱往往功能堆叠、界面嘈杂，打开和滑动时也容易显得沉重，后台计算期间掉帧常有出现。
因此，为了我自己的体验，该软件的设计思路是：去掉多余累赘，把帧率、流畅和手感放在第一位，再用现代、克制的视觉语言把界面做干净。

## 目标

- **交互要丝滑**：把丝滑流畅放在第一位，合理的回弹、交互手感、短长按手势交互才是一个舒适软件的精髓。
- **性能优先**：去掉大厂邮箱里常见的繁重和累赘，只保留收信与阅读真正需要的部分，所有计算行为均为了性能表现而让路，不因为后台工作而卡顿或发烫。
- **现代化视觉语言**：用现代的设计语言来处理视觉。界面干净，光效克制，方便长时间扫读。

## 功能

- **多账号聚合。** 登录多个账号时，不同账号可以分开查看，也可以直接聚合查看。每一行都能看出信件来自哪个账号。还可以自定义指定账号为一组。
- **分类与轻量标签。** 每封邮件交给大语言模型判断类型，分为重点、验证、通知、推广和垃圾。同时还可以打上0~3个短标签，短标签用来帮助快速分辨邮件特征，以及用于按标签筛选。
- **折叠屏适配。** 我自己在使用折叠屏，因此按这个场景做了专门优化，主要是展开后的宽屏左右栏适配。

## 开发状态

Ainsmail 仍处于开发阶段。当前版本还不能作为日常邮箱使用，功能和界面都会继续调整。
